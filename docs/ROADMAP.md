# Roadmap

## v0.1 - proof of concept

- native Windows app shell
- configurable username
- fixed Camledian Commander WebDAV endpoint
- secure credential storage
- rclone process wrapper
- mount / unmount
- connection state
- open drive in Explorer
- basic diagnostics

## v0.2 - daily-use reliability

- tray icon
- start with Windows
- automatic reconnect
- sleep/resume handling
- network-change handling
- VFS cache settings
- self-test / dependency checks

## v0.3 - distribution

- installer
- automatic build through GitHub Actions
- code signing pipeline
- automatic update strategy
- dependency/license notices

## v0.4 - Camledian account experience

- browser-based login or short-lived access token
- revoke sessions from Commander
- multiple server-side roots / shares if required
- richer account and quota status
